# 사운드보드 채널 및 메시지 보관

- `/음성채널`로 지정한 전용 텍스트 채널에서만 음성 명령, `/음성`·`/음성목록`, 음성 추가·삭제, 사운드보드 버튼을 사용한다.
- 지정 채널이 없으면 현재 Discord 서버의 이름이 정확히 `사운드보드`인 채널을 찾는다. 없으면 보탐매니저 채널에 대신 출력하지 않는다. 전용 채널에서 `/음성채널`을 실행하면 된다.
- 최초 고정 사운드보드도 같은 전용 채널에 게시한다. 보탐매니저 채널에 남은 패널은 저장된 메시지 ID·작성 봇·패널 제목이 확인되는 경우에만 새 패널 게시 후 삭제한다. 남은 옛 패널 버튼은 다른 채널에서 실행되지 않는다.
- `/보탐`은 기존 스케줄 조회, `/보탐 접속`은 기존 접속 기능을 유지한다.
- `/보탐 ?`는 현재 등록된 모든 명령어와 예시를 보여준다. 슬래시 명령에서는 `동작`에 `?`를 입력한다.
- 프로그램의 스케줄 입력·추가 및 디스코드 입력 모두 `2120 그로아, 헤이드, 티르` 문법을 지원한다. 각 보스에 동일 시각을 적용하고, 소수점 초와 중복 경고를 보존한다.
- `/보탐 초읽기`는 초읽기 사용을 켜고 `/보탐 초읽기해제`는 끈다. 같은 명령을 반복해도 반대로 토글하지 않는다. 슬래시 명령의 `동작` 입력란과 보탐매니저 채널의 일반 텍스트 명령을 모두 지원한다.
- 초읽기는 로컬 프로그램의 기존 체크박스 처리 경로로 적용·저장하며, 해제 시 기존 초읽기 대기열/음성 중단 절차를 따른다. 알람 전체 ON/OFF나 시작 초 값은 변경하지 않는다. Discord 응답은 요청 전달 확인이며, 실제 적용 결과는 프로그램의 디스코드 요청 기록에 남긴다. 관리자 인계 중에는 적용하지 않는다.
- `/보탐`의 선택 입력란 `동작`에 `0`~`50`을 입력하면 보탐매니저 메시지 보관 수를 저장한다. `0`은 무제한이며 삭제하지 않는다. 최초 기본값은 기존과 같은 `2`다.
- 일반 채팅으로 입력한 `/보탐 0`~`/보탐 50`도 보탐매니저 채널에서 처리한다. 이 방식은 Discord Message Content Intent가 활성화되어 있어야 한다. 슬래시 명령은 이 조건과 무관하다.
- 보관 수는 봇 자신의 일반 메시지 개수 기준이다. 사용자 글과 고정 메시지는 건드리지 않는다. 긴 스케줄이 여러 메시지로 분할되면 각각 하나로 계산한다. 같은 안내채팅에서 사용하는 승계 제어 메시지는 보관 개수·자동 정리에서 제외하며 자체 60초 삭제 수명을 따른다.
- 제한을 줄이면 기존 봇 메시지도 정리한다. 이미 삭제된 글은 나중에 보관 수를 늘려도 복구되지 않는다. 읽기/메시지 삭제 권한 부족 시 정리되지 않을 수 있다.
- 설정은 활성 봇 설정 INI의 `[discord_bot] text_channel_keep_count`에 저장하며 GUI 설정 저장 시에도 유지한다. 사운드보드 전용 채널의 기존 정리 규칙(고정 패널 + 최근 메시지 1개)은 별개다.

비빌드 검증: `python -B -m unittest test_discord_channel_policy test_discord_connection_control test_discord_server_isolation`

소스 적용 후 봇을 재시작하면 슬래시 명령 정의가 갱신된다. 실제 Discord 송출/접속 및 배포 빌드는 수행하지 않는다.

## 소스 패치가 반영되지 않는 실행 경로 수정

2026-09-22 확인: 소스로 실행한 GUI도 `dist/boss_timer_discord_bot.exe`를 우선 실행하여, 9월 10일 빌드에 최신 명령이 반영되지 않는 문제가 있었다.

- 개발 실행은 현재 `boss_timer_discord_bot.py`를 우선 사용한다. 정상 실행과 연결 정리용 실행에 같은 선택 규칙을 적용한다.
- 배포 GUI EXE는 계속 동봉된 봇 EXE를 사용한다. 배포 시에는 사용자가 GUI와 봇 모두 다시 빌드해야 한다.
- 이미 실행된 GUI는 이전 실행 경로를 가지고 있으므로 프로그램 전체를 종료 후 소스로 다시 실행한다. 실행 중인 봇이나 배포 파일은 수정 작업 중 강제로 중단·삭제하지 않는다.
- 봇 로그에 `discord_runtime_loaded mode=source/exe path=... channel_policy=2`, 명령 등록 완료 표시, 사운드보드 초기 게시 결과/채널 없음 이유를 남긴다.
