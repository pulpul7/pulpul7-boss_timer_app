# 초정밀 측정 후 남은 시간 1초 차이 (2026-10-01)

게임이 2분 5초인데 스케줄이 2분 6초로 표시되는 신고를 소스로 점검했다.
`precision_time_tracker.BossTimeTracker`는 게임 남은 시간이 내림 표시된다고 가정한다.
R → R-1 표시 전환 시점에 R초가 남았다는 기준으로 출현 시각을 계산하며,
분 단위와 초 단위 측정 모두 이 기준을 사용한다. 초 단위 후속 전환은 관측한 횟수만큼
감산하고 `GameClockTracker`를 통해 게임시각에 대응한다.

확인된 표시 차이는 다음 두 경로에서 발생했다.

- 스케줄 상단의 다음/그다음 보스 남은 시간과 선택 보스의 초확정 보정 표시가
  `math.ceil`을 사용했다. 남은 시간이 125.2초면 126초로 표시되어 내림 값인 125초보다 1초 크다.
- 상단 남은 시간의 기본 갱신은 PC 정수 초에 맞춰져 있었다. 측정 출현 시각에 소수점이 있으면
  표시가 바뀌는 시점도 해당 소수점 위상에 맞춰야 한다. 올림만 제거해도 갱신을 기다리는 동안
  차이가 남을 수 있다.

두 남은 시간 표시는 0 이상 정수 내림으로 통일했다. 상단 요약에는 다음/그다음 출현 시각으로부터
다음 내림 표시 변경 시점을 계산해 해당 경계에서 추가 갱신한다. 기존 정수 시계 갱신과
선택 보스의 100ms 보정 미리보기 갱신은 유지하며, 매번 전체 요약을 고속 재계산하지 않는다.

초정밀 측정식, 분 단위 측정식, 저장된 소수점 출현 시각, 알람/Discord 송출 기준은 변경하지 않았다.
니드호그의 저장 시각을 임의로 1초 당기거나 기존 사용자 스케줄을 수정하지 않았다.
실제 게임의 표시 내림 여부, PC와 게임시계의 차이 및 실제 출현 시각까지 이번 소스 점검으로
확정한 것은 아니다. 실제 출현도 어긋나면 추가 계측 결과가 필요하다.

소스 문법과 변경사항만 확인하고 프로그램·테스트·빌드는 실행하지 않았다.
