# 일반 스샷 촬영 창 처리

- 스케줄 입력창을 연 후 첫 `스샷찍기` 버튼/F2 요청만 프로그램 소유 창 상태를 보관하고, 메인 창을 최소화하며 열린 팝업을 숨긴다. 이미 최소화/숨김 상태였던 창도 원래 상태를 유지해 복원한다.
- 같은 입력 세션의 두 번째 촬영부터는 기존처럼 작은 캡처 애드온 창만 잠깐 숨긴다. 입력창을 닫거나 새로 생성하면 첫 촬영 상태가 초기화된다. 애드온만 닫았다 다시 여는 것은 새 입력 세션이 아니다.
- 캡처가 끝나면 기존 완료 피드백/복원 지연 타이밍에 맞춰 창을 복원한다. 복원 완료 전 새 촬영은 차단하며, 실패·중복·작업 시작 실패·창 닫기에서도 남은 창이 숨겨진 채 유지되지 않게 한다.
- 첫 촬영 직후 창을 닫는 경우 먼저 촬영 전 상태를 복원하고 입력창을 닫아, 닫은 입력창이 지연 콜백으로 다시 나타나지 않게 한다. 이전 세션의 늦은 캡처 결과는 새 촬영 상태를 변경하지 않는다.
- 초정밀 촬영의 전체 창 숨김/첫 캡처 후 진행창 표시 흐름, OCR1/OCR2 분석 알고리즘은 변경하지 않는다. 실제 Windows 최소화 애니메이션과 게임 캡처는 사용자가 확인하며 자동 검사는 가짜 창/가짜 이미지로만 수행한다.
