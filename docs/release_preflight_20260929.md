# v5.5.1 배포 전 점검 (2026-09-29)

## 버전 확정

- 사용자가 v5.0.1이 아니라 **v5.5.1**이라고 확인했다.
- GUI 기본 버전, 빌드 spec, 빌드 메타데이터, ZIP 버전 추출의 fallback, init/assets seed 표식을 v5.5.1로 통일했다.
- 패치내역에 새 시즌 스케줄 복사, 디코 설정 승계, 이전 시즌 담당 기록 정리, 중복 봇 실행 방지, 시즌 변경 전 파일 접근 검사를 추가했다.
- 실제 배포 전이므로 패치내역 상태는 '배포 준비 중'이다. 마지막 배포 기준은 v5.3.1.fix이며 v5.5.0을 배포했다고 표시하지 않는다.
- 공지/AI 모듈 버전은 본체와 별개다. 업데이트 센터는 본체 EXE 자동 교체 도구가 아니다.

## 확인 완료

- 사용자 실측: 스케줄 입력 → 새 시즌 → 디코 연결 → 이전 시즌 담당 확인 후 로컬 스케줄 승계 성공.
- 사용자 실측: 디코 연결 중 새 시즌 → 연결 종료 → 이전 시즌 담당 확인 후 로컬 스케줄 승계 성공.
- 비빌드 회귀 검사 첫 묶음 132개 통과: 저장소, 시즌/프로필 복사, 담당자 ID, 인계, 중복 접속 방지, 봇 실행 경로, TTS TLS, 버전/패치내역.
- 추가 검사 55개 통과: 배포 리소스 검사, 버전/패치내역, 초정밀 자동적용, 캡처 창 숨김, 소수점 시간, 여러 보스 문법, 알리미 기본값. 일부 검사는 첫 묶음과 중복된다.
- spec을 실행하지 않고 실제 리소스 파일 목록을 수집해 토큰 설정 파일·담당자 ID·서버 프로필·스케줄 파일과 로그/임시 파일의 제외를 검사했다. 음성/TTS 캐시 파일 자체의 내용 심사는 아니다.
- 배포 EXE의 상세 디버그 로그는 기본 꺼짐. 오류/운영 로그는 유지한다. discord_voice_queue.jsonl은 통신 파일이므로 정리 대상으로 삭제하면 안 된다.
- 현재 Python에서 PyInstaller, truststore 0.10.4, discord, PyNaCl을 찾을 수 있고 FFmpeg 파일도 존재한다. EXE 실행 검증을 대신하지는 않는다.
- git diff --check 통과. 기존 사용자 설정, 스케줄, 음성, 배포본 및 로그는 삭제하지 않았다.

## 배포 전 남은 확인

1. 사용자가 GUI와 디코봇을 **둘 다** 빌드한다. `python build_release.py`가 두 EXE와 ZIP을 생성하는 기존 수동 경로다. 이번 점검에서는 실행하지 않았다.
2. 기존 프로그램을 완전히 종료한 뒤 새 파일로 실행하여 AppData의 담당자·길드·시즌·서버·스케줄 및 디코 설정이 유지되는지 확인한다. AppData를 지우지 않는다.
3. 새 EXE에서 차임벨/초읽기와 사운드보드, TTS 설치를 확인한다. 인증서 오류가 났던 다른 PC의 Windows 신뢰 저장소 상태까지 이번 로컬 검사가 보장하지는 않는다.
4. 두 관리자 사이의 실제 원격 인계는 아직 별도 실측 대상이다. 이번에 사용자가 통과한 것은 동일 PC의 시즌 전환 경로다.
5. 수동으로 배포 파일을 묶는다면 개인 INI, administrator_identity.json, server_profiles, notice_data, 로그를 함께 복사하지 않는다. 기존 사용자의 개인 음성은 보존한다.

## 알려진 미완료 범위

후속 작업에서 알리미 자동 Discord 송출과 실제 1분 전 안내 완료 기회 연결을 추가했다. 자동 출력 설정은 기존 값을 유지한다. 아직 실제 Discord 재생/선점/재개 실측은 하지 않았으므로 `docs/notice_implementation_steps.md`의 2026-09-29 항목에 따라 사용자 확인이 필요하다. 로컬 자동 방송 및 `/공지`·`/중지` 명령 UI는 별도 후속 작업이다.

보관 관리는 AppData의 archive_logs를 사용한다. 서버·길드명이 포함된 시즌 폴더도 정리하며, 상세에 실제 경로를 표시한다. 옛 설치 폴더의 저장된 로그 조회 경로는 현재 AppData로 연결한다. 보관 정리는 기록 폴더만 정리한다. 2026-10-01에 추가한 명시적인 과거 시즌 전체 삭제는 해당 시즌의 서버 설정·스케줄도 삭제하며, 현재 사용 중인 시즌은 보호한다. 실제 로그 삭제는 이번 작업에서 실행하지 않았다.

2026-10-01 빌드 전 소스 점검: 시즌 폴더 즉시 생성, 과거 시즌 이어하기, 폴더 없는 이력 관리,
구형 롤백 폴더의 삭제 접근 거부 처리를 반영했다. 새 시즌 시작·이어하기에서 활성화 또는 저장이
실패하면 이전 시즌 상태로 돌아가고, 되돌린 상태를 저장하지 못하면 별도로 안내한다.
버전은 v5.5.1을 유지한다. 최근 시즌 기능과 권한 복구는 사용자 실측이 남아 있으며,
이번 점검에서는 소스 문법 및 diff 확인만 수행하고 프로그램·테스트·빌드는 실행하지 않았다.

실행 파일, ZIP, 테스트 배포 폴더를 만들지 않았고 GitHub 업로드·태그 생성도 하지 않았다.
