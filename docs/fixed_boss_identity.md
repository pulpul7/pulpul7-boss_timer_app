# 고정보스 이름 수정과 웹 연결

고정보스 수정은 새 항목 추가와 구분합니다. 목록에서 기존 항목을 선택해 수정하면 표시 이름·시간·요일을 바꾸더라도 `web_identity`를 유지합니다. 웹 사용자 보스 선택과 스펙트럼 배경색은 이 ID에 연결됩니다. 고정보스 파일의 아홉 번째 선택 필드 `웹연결ID`와 관리자 동기화 자료에도 포함합니다. 이전 7·8필드 파일은 계속 읽습니다. 이름만으로 보스를 구분하던 기존 파일은 이전 이름으로 계산한 ID에서 시작합니다.

이미 이름을 바꾼 아래 항목은 띄어쓰기를 무시하고 같은 항목으로 연결합니다.

| 동일한 명칭 |
| --- |
| 길던 / 길드던전 |
| 쟁탈전 / 길드쟁탈전 |
| 방어전 / 길드방어전 |
| 점령전 / 길드점령전 |
| 알브 닻 / 알브하임 닻 |
| 니다 닻 / 니다벨 닻 / 니다벨리르 닻 |

웹 목록은 과거 이름의 ID를 함께 전달합니다. 브라우저는 기존 개인 선택을 새 ID로 옮기며 저장 전 수정 중이던 선택과 자동 저장 시각은 유지합니다. 스펙트럼도 과거 ID의 색을 복원하고, 동일 항목에 중복 색이 있으면 현재 ID의 값을 우선합니다. 서로 다른 지역의 닻, 통합 닻, 신청·신청마감 항목은 합치지 않습니다.

음성 파일은 적힌 이름을 먼저 찾고 없을 때 위 명칭을 순서대로 찾습니다. GUI의 고정보스는 지역 이름을 일반 약칭 `닻`보다 먼저 찾습니다. 이름·음성 파일을 강제로 바꾸지 않습니다.

현재 설정 반영은 `python -B promote_boss_defaults.py --apply --include-spectrum`으로 진행했습니다. 보스 51개·지역 9개·고정보스 30개와 현재 스펙트럼이 배포 기본값에 들어가고, 활성 오9 시즌18의 보스·고정보스 롤백 기준도 갱신됐습니다. 이전 값은 `settings_seed_backups/boss_defaults_20261015_211906_128953`에 보관했습니다. 다른 서버 스케줄·알람 설정·음성 파일은 이 작업에서 수정하지 않습니다.

실행 파일은 생성하지 않았습니다. 배포 시 변경된 Discord 봇과 GUI를 함께 재빌드해야 합니다.

검증: `test_fixed_boss_aliases`, `test_web_boss_catalog`, `test_web_boss_spectrum`, `test_promote_boss_defaults`, `test_web_fixed_aliases.js`.

기존 AppData에도 배포자가 선언한 기본값을 한 번 적용하는 절차는 [배포 기본설정 선언](distribution_defaults.md)을 참고합니다.
