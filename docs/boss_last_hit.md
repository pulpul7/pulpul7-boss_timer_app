# 막타 표시

보스설정의 `막타` 체크는 보스명과 분리된 `last_hit` 값이다. 기본은 해제다.
목록의 막타 칸을 누르면 바로 저장되며 오른쪽 편집 폼에서도 변경할 수 있다.

- 표시: 보스스케줄 목록·출현 패널, 웹 일정·선택 목록, Discord 보탐 조회·보스 안내 메시지.
- 복사: 프로그램의 스케줄 복사 이미지, 웹 이미지 복사·저장과 텍스트 복사·TXT 저장.
- 제외: 프로그램 `스케줄 복사` 옆의 `TXT`는 입력창에 넣는 텍스트이므로 표시를 넣지 않는다.

원본 보스명·약칭·OCR 명칭·스케줄 키·일정 ID·음성 이름은 바꾸지 않는다.
공유용 행과 웹 API의 이름도 그대로 두고 별도 boolean을 전달하여 마지막 출력 단계에서만
`보스명 (막)`으로 표시한다. 설정 변경은 기존 일정을 삭제하거나 재생성하지 않는다.
입력/이름 조회에서는 `티르(막)`, `티르 (막)`의 표기만 제거하여 순수 이름으로 처리한다.
표기를 붙여 입력하는 것으로 막타 설정이 켜지지는 않는다.

설정 TXT는 기존 9개 열 뒤에 막타 여부(1/0)를 10번째 열로 추가한다.
구형 8/9열 파일은 막타 해제로 읽는다. 공유 보스설정에도 포함하며 구형 공유 자료에
필드가 없으면 현재 설정을 보존한다. 진단 로그는 `schedule_boss_last_hit_changed`다.

GUI와 Discord 봇 양쪽 소스가 변경되었다. 배포 시 양쪽을 재빌드하고 웹 자산 개정 69를
포함해야 한다. 별도 워커 EXE는 만들지 않는다.
