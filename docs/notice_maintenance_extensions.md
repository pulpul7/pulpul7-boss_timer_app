# 같은 점검 공지의 본문 수정과 연장 안내

정기점검 제목이 그대로여도 본문의 확정된 연장 표시(예: `3시간 30분 연장`, `점검 연장 안내`)를 읽는다.
또는 같은 글에서 시작 시각이 같고 명확히 확인한 종료 시각이 이전보다 늦어지면 연장으로 분류한다.
`연장될 수 있습니다`와 같은 일반 유의사항은 연장으로 분류하지 않는다.
완료·취소 제목은 과거 본문에 남은 연장 표시보다 우선한다.

HTML의 `s`, `strike`, `del`, 인라인 `line-through`로 표시한 이전 시간은 기존 수집기에서 제외한다.
원래 기간과 연장 기간이 모두 남아 있어도 명시적인 연장 표시가 있고 시작 시각이 모두 같으면
가장 늦은 확정 종료 시각 하나를 사용한다. 서로 다른 시작 시각 등 불명확한 경우는 확인 필요로 유지한다.

이전 종료 시각이 지나 자동으로 만료된 점검 알림에 한해, 동일 점검의 새 종료 시각이 현재보다 늦으면
같은 알림을 새 개정으로 갱신한다. 이전 만료로 생긴 차단 표식도 이 경우에만 해제한다.
이로써 같은 공지를 세 번 수정해 연장해도 각 변경은 한 번씩 안내할 수 있고, 동일 본문 재조회나
감사 문구 등의 수정만으로는 완료한 안내를 반복하지 않는다.
사용자 OFF, 직접 폐기, 수동 기간, 수집·유형 OFF는 유지한다. 기존 음성 출력과 Discord 채팅 경로를 사용한다.

로컬 기록에는 2026-10-14 08:27 봇 종료와 18:31 재접속이 있으며,
정기점검 원문은 08:20 확인, 완료 글은 18:31 처음 확인되어 있다.
이 PC 기록만으로 그 사이 다른 관리자 PC에서의 연장 수집·송출 여부는 확인할 수 없다.
실제 Discord 전송은 하지 않고 오프라인 수집·등록·가상 송출로 검증한다.

회귀 검증: `test_notice_maintenance_extensions.py`, `test_notice_chat_output.py`.
실행 파일이나 배포 ZIP은 생성하지 않는다.
