# edge-tts 음성 설정

보스타이머의 알림 음성 우선순위는 다음과 같습니다.

1. `voice` 폴더의 기존 음성파일
2. 알림 전에 미리 생성한 edge-tts 음성
3. edge-tts 생성 실패 시 음성 출력 생략 (Windows/MS TTS 자동 대체 안 함)

## 설치

```powershell
python -m pip install -r requirements-gui.txt
```

배포용 EXE를 만들 때는 `edge-tts`가 설치된 Python 환경에서 `boss_timer_gui.spec`을 사용합니다.

## 설정 방법

1. **알람 설정 > edge-tts 설정**을 엽니다.
2. `edge-tts 음성 사용`을 체크합니다.
3. 음성 모델을 선택합니다.
4. 말하기 속도, 음량, 음높이를 슬라이더로 조절합니다.
5. **캐싱 데이터생성**을 눌러 현재 보스·고정보스·알림 문장의 음성을 미리 만듭니다.
6. 진행 창이 자동으로 닫히면 **음성 테스트**로 확인한 뒤 저장합니다.

한국어 기본 모델은 `ko-KR-SunHiNeural`입니다. 설정 창은 Microsoft의 현재 한국어 음성 목록을 온라인으로 불러오며, 조회에 실패하면 앱에 포함된 기본 한국어 모델 목록을 사용합니다.

설정은 Windows 사용자 설정 폴더의 `BossTimer/edge_tts.ini`에 저장됩니다.

## 영구 캐시와 폴백

- 초읽기 1~59초는 `tts_캐쉬/sec/1.mp3`부터 `59.mp3`까지 미리 생성하여 재사용합니다.
- 초읽기 숫자는 일반 알림 대기열과 분리된 비차단 전용 재생 호스트에 선로딩하여 매초 즉시 교체합니다.
- 디스코드 봇도 `AI 녹음파일 우선 사용` 체크 상태를 따르며, 체크 해제 시 같은 edge-tts 캐시 MP3를 전송합니다.
- 사용자 이벤트·일반 보스·고정보스와 현재 설정에서 만들 수 있는 알림 문장도 `tts_캐쉬`에 영구 저장합니다.
- 동일한 문장과 음성 설정은 중복 생성하지 않으며 앱을 다시 시작해도 저장된 MP3를 읽습니다.
- 음성 모델·속도·음량·음높이가 바뀌면 이전 캐시를 잘못 재사용하지 않고 새 설정으로 생성합니다.
- 보스·고정보스 저장 또는 목록에 없는 이름을 일정에 추가할 때 필요한 캐시가 없으면 `TTS 캐쉬 생성중` 진행 창을 표시하고 완료 후 자동으로 닫습니다.
- 미리 만들 수 없었던 동적 문장은 첫 생성 후 같은 영구 캐시에 보관합니다.
- 인터넷 연결 실패, 서비스 오류 또는 패키지 누락 시 Windows/MS TTS로 자동 대체하지 않습니다.
- 선택한 한국어 edge 음성이 `NoAudioReceived`를 반환하면 사용 가능한 다른 한국어 edge 음성으로 자동 전환합니다.
