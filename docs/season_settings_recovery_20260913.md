## 소스 수정

- 새 시즌은 같은 서버의 직전 활성 시즌(없으면 가장 최근 이전 시즌)에서 설정과 롤백 기준점만 이어받는다.
- 이전 스케줄, 삭제 이력, OCR 측정 결과는 새 시즌에 복사하지 않는다. 평면 폴더의 전체 이관은 해당 서버의 최초 시즌 이관 때만 허용한다.
- 이미 존재하는 프로필은 자동 덮어쓰지 않는다. 복사 실패 시 불완전한 새 프로필을 공개하지 않고 서버 선택도 이전 값으로 돌린다.
- 롤백 기준점의 대상 경로를 새 프로필로 갱신한다. 실제 롤백은 기록된 절대 경로 대신 현재 프로필의 허용된 설정 경로만 사용한다.
- 누락된 롤백 스냅샷은 복원 전에 검사한다.

## 배포 주의

이 수정은 본체 기능이다. 공지/AI 모듈 ZIP 업데이트로는 수정되지 않으며, 사용자가 본체를 수동 빌드·배포해야 한다. 이번 작업에서는 EXE/ZIP을 생성하지 않았다.

이미 설정이 빠진 기존 프로필은 업데이트만으로 자동 복원하지 않는다. 해당 PC의 정상 설정/백업을 확인하고 스케줄을 보존하며 별도로 복구해야 한다.

## 추가 재현: AppData 없는 최초 설치 / 다른 서버

이후 사용자가 제공한 재현으로 앞선 동일 서버의 시즌 승계 수정만으로는 부족함을 확인했다.

- 공용 init에는 배포 설정이 있지만 새 서버 프로필에는 기본 파일을 채우는 단계가 없었다. `_seed_init_file_from_resource` 역시 프로필이 아닌 공용 init에만 기록했다.
- 열린 설정창은 전환 전 내용을 계속 보여줄 수 있어, 창을 미리 열었는지에 따라 결과가 달라 보였다.
- 최초 실행 때 선택한 시즌의 서버를 즉시 선택하지 않아 서버 표시가 비어 있는 경로가 있었다. 새 시즌에 다른 서버명을 입력해도 종전 서버를 활성화하는 경로도 수정했다.
- 새/기존 프로필의 **없는 파일만** 배포 기본값으로 채운다. 기존 파일(의도적인 빈 파일 포함), 스케줄, 기존 롤백 기준점은 자동 덮어쓰지 않는다.
- 최초 롤백 기준점은 창을 처음 열었을 때의 현재 상태가 아니라 배포 기본값으로 만든다. 필수 파일이 없는 기준점으로는 성공 메시지를 표시하지 않는다.
- 이미 잘못된 기준점이 있는 경우를 위해 롤백창에 `배포 기본값` 복구 버튼을 추가했다. 명시적 확인 후 선택한 설정을 백업·복구하며 기존 기준점은 보존한다. 일반 `확인`은 기존 기준점을 계속 사용한다.
- 서버 전환/롤백 뒤 열린 설정창 및 미저장 편집 상태를 갱신한다.

추가 수정 검증: 총 115개 중 114개 통과, Tk 검사 1개 제외. 임시 폴더에서 최초 서버 생성, 설정창 미개방 상태, 다른 서버, 기준점 오류, 배포 기본값 복구 후 실제 고정보스 로더 재읽기를 검사했다. 이 추가 작업에서는 실제 AppData와 배포 파일을 수정하지 않았다.
